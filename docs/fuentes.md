## Qué se verificó en el controlador Maqueen

El código del commit identificado usa para motor un buffer de tres bytes con dirección I²C `0x10`, registro `0x00` para el motor izquierdo, `0x02` para derecho, byte de dirección y velocidad. S1/S2 seleccionan registros `0x14`/`0x15` para el servo. `Ultrasonic()` reemplaza lecturas fallidas por 500; por eso la nueva API no presenta ese valor como camino despejado y devuelve `-1` si el pulso no es válido. El controlador también contiene tareas globales y bloques de otros modelos; no se importa como dependencia.

No se recuperó fuente de los demos compartidos ni `.hex` y no se afirma que sus bloques hayan sido inspeccionados o que conviertan JavaScript↔bloques.
